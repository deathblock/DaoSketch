# DaoSketch

DaoSketch enables real-time, distributed data processing and rendering in a scalable, auto-configurable system architecture framework.

With DaoSketch, you get a lightweight tool that stays out of your way.

**What you get**

- DaoSketch enables real-time, distributed data

- javascript

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoSketch.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure DaoSketch, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
